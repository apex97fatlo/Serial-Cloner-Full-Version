## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **DNA Sequence Management** — Effortlessly read and write DNA sequences and manage your projects.
- **File Compatibility** — Import/export files in FASTA format and from programs like Vector NTI, GenBank, and more.
- **Graphical Analysis** — Analyze sequences graphically with the ability to take notes within the application.
- **Nucleotide and Peptide Creation** — Create custom nucleotides and peptides with ease.
- **Tm Calculator** — Calculate the melting temperature (Tm) of selected fragments for optimal analysis.

### Advanced Features:
- **Subproject Configuration** — Configure new subprojects and prepare electronic versions of your constructions.
- **Restriction Mapping** — Find restriction sites and select fragments numerically for precise editing.
- **Subsequence Extraction** — Extract subsequences to create new fragments based on your research needs.
